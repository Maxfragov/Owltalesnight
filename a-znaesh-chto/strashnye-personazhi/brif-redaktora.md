# Бриф редактора: арка «немного страшно» (s01–s10)

> **Действует решение: 16+, максимально страшно** (Владислав). Аудитория — подростки и взрослые, метка 16+, жуть-метр 4–5, разгадка — последняя мурашка, страх не отпускает (строка 11 без морали). Совёнок прячется за луну на жуткой части. Ниже — исходный детский бриф: разделы 2 (строка 11 «страх отпускает», перелом «тёплое слово»), 5 (детская аудитория, «монстр всегда в кино») и направления финалов в 4 (смешная правда, «и оно смешное») **отменены**. Остаются: строки 1/13, 13 строк, 80–100 слов, «ё», без тегов, проверенные факты, без крови, описания убийств и способов смерти, без скримеров и копий облика. Финальные тексты: teksty-final.md; правила арки — bibliya-serii.md, раздел 8.

Для писателя. Источники: bibliya-serii.md, 10-idey.md, сценарии 01–05. Формула арки: **мурашки атмосферой → разгадка «монстра сделали люди» → страх отпускает**. Голос тот же, бабушка Валя, только тише и медленнее.

## 1. Что сохраняем из серии

| Элемент | Правило |
|---|---|
| Строка 1 | «А знаешь что...» |
| Строка 13 | «Спокойной ночи. Завтра расскажу ещё.» |
| Размер | 13 строк, ~90 слов (допуск 80–100) |
| Строка 2 | факт-хук одной фразой. В арке подаётся загадочно, без разгадки («Самое страшное лицо в кино стоило меньше двух долларов.») |
| Строка 2 у соседей | не начинать с одного и того же слова |
| Буква «ё» | везде, без исключений (ещё, всё, её, тёмный, чёрный, шёпот) |
| Паузы | без `<break>` и любых тегов; паузу делает точка или многоточие |
| Разметка | одна строка = один абзац для ElevenLabs |
| Факты | только проверенные, источники внизу scenariy.md; неизвестное — через «может быть» |
| Совёнок | на луне в начале и в конце; в жуткой части может спрятаться за луну и выглянуть в финале |

## 2. Обязательная структура

| Строки | Функция | Что в тексте |
|---|---|---|
| 1 | вход | «А знаешь что...» |
| 2–7 | жуть | факт-хук + атмосфера: звук, тень, пауза. Монстр — намёком, не описанием |
| 8–10 | разгадка | как это сделали люди: маска из магазина, нитки, кукловоды, плёнка, сон сценариста |
| 11 | вывод | обобщение, страх отпускает («страшное придумали люди») |
| 12 | финальный ход к зрителю | по типу из таблицы 4 |
| 13 | выход | «Спокойной ночи. Завтра расскажу ещё.» |

Перелом (строка 8) должен быть слышен: первое тёплое или смешное слово в тексте.

## 3. Не повторять (закрыто выпусками 1–5)

| Что | Где было | Статус в арке |
|---|---|---|
| «Держи за лапку…» (жест рукой к близкому) | 1 | закрыто; жест в арке — только другой |
| «Закрывай глаза. Сон тоже…» | 2 | закрыто |
| «Тебе сейчас тоже можно только спать» | 3 | закрыто |
| «тоже» / «и ты» в строке 12 (зверь спит → и ты) | 2, 3, 4 | закрыто для всей арки |
| «Пусть всё громкое уснёт…» | 4 | «пусть» можно, но не про сон и не «уснёт первым» |
| «А мы с тобой послушаем тишину» | 4 | «мы с тобой» можно, но не «тишину» |
| «Ночь тёмная, а сны бывают цветными» | 5 | закрыто |
| «Наверное, …» в начале строки 11 | 1, 2 | не больше 1 раза на арку |
| «Даже …» как ударная фраза строки 11 | 4, 5 | закрыто для арки |
| «Тук. И…» / «И снова…» как ритм-петля | 3 | закрыто (стук в арке — без этой петли) |
| удвоения «тихо-тихо», «долго-долго», «далеко-далеко» | 1, 2, 3 | не больше одного на выпуск, и не эти три |
| «ничего не нужно/надо + глагол», «только спать» | 3, 4 | закрыто |
| «Сейчас, пока ты засыпаешь», «Укладывайся поудобнее» | 3 | закрыто |
| мама + малыш | 1, 4 | не использовать |
| пузырики, «всплывает» | 4, 5 | закрыто (колодец в s10 — без пузыриков) |
| «Вдруг» как старт поворота | 5 | не больше 2 раз на арку, не у соседей |
| Сравнения: как одеяло (навсегда), как поплавки, как ракушка, как вода в холодильнике | 1–5 | закрыто |
| «луна», «звёзды» в тексте | свободны | можно, но не чаще 1 раза на 3 выпуска |

## 4. Назначения по выпускам

Типы финала (строка 12): **А** жест · **Б** закрой глаза + образ · **В** разрешение · **Г** пожелание «пусть» · **Д** «мы с тобой» · **Е** образ без глагола · новые: **Ж** выключи свет страху · **З** перемотай назад · **И** смешная правда · **К** убери страх (в коробку, в тетрадку).

| № | Персонаж | Финал 12 (тип) | Направление финала | Сравнение «как…» (одно) | Жуткий приём 3–7 |
|---|---|---|---|---|---|
| s01 | Франкенштейн | Д «мы с тобой» | мы с тобой сочиним историю, только добрую (без слова «тоже») | как свеча на сквозняке | капли: дождь стучит в окно виллы |
| s02 | Майерс | И смешная правда | под страшным лицом — перекрашенный капитан из космоса | как чистый лист | тишина: никто не говорит, шаги стихают |
| s03 | Чаки | А жест | пошевели пальцами: вот и все «ниточки» | как оркестр | скрип: крышка ящика с игрушками |
| s04 | «Крик» | К убери страх | маска обратно в коробку, крышку закрыть | как забытая игрушка | шорох: в картонной коробке на чердаке |
| s05 | Джейсон | В разрешение | бояться понарошку можно, монстр собран из кусочков | как поделка | хруст веток в лесу у лагеря |
| s06 | Носферату | Ж выключи свет страху | щёлкни выключателем: тень пропадёт | как карандаш (длинная тонкая тень) | тень на лестнице |
| s07 | Пеннивайз | Г «пусть» | пусть шарики улетают, каждый в свою сторону | как два шарика на ветру | хлопок: лопнул шарик, и пауза |
| s08 | Фредди | Е образ без глагола | красный и зелёный вместе — это ёлка, а не страх | как ёлочная гирлянда | счёт: «раз… два…» (свой, не считалка из фильма) |
| s09 | Синистер | К убери страх | кошмар записан, тетрадка закрыта | как письмо самому себе | шёпот (и скрип ручки по бумаге) |
| s10 | «Звонок» | З перемотай назад | перемотай страшное назад — и оно смешное | как пятится рак | звонок телефона в пустой комнате |

Проверка: соседние типы финала разные; К — 2 раза (s04, s09), остальные по 1. Сравнения все разные, закрытых нет. Жуткие приёмы у соседей разные. Перед s01 сверить его финал с последним вышедшим выпуском основной серии (сейчас 5 — тип Е, конфликта нет).

## 5. Ограничения по жути (детская аудитория)

| Нельзя | Можно вместо |
|---|---|
| убийства, смерть, «погиб», «утонул», любые способы смерти | «страшная история», «злодей из кино» |
| кровь, раны, укусы (Носферату — без «кусает», без «крови») | тень, длинные пальцы-тень, плащ |
| оружие: нож, мачете, топор, лезвия, когти как оружие | у Фредди только «перчатка», без лезвий в тексте; у Джейсона — маска и клюшка |
| пересказ сюжета, жертвы, погони | факт о съёмках |
| «через семь дней…» (s10), похищения, «утащил» (s07), «из частей тел» (s01) | «кассета», «колодец», «шарик», «собрал из кусочков истории» |
| монстр рядом со зрителем: «под твоей кроватью», «за тобой», «в твоём шкафу» | монстр всегда «в кино», «на плёнке», «в книжке» |
| копии облика, кадров, музыки | оригинальные намёки (см. 10-idey.md) |

| Названия | Правило |
|---|---|
| Название фильма | можно один раз за текст, в разгадке (строки 8–10) |
| Имя персонажа | можно, сколько нужно по смыслу |
| Клоун (s07), кошмары (s08–s10) | самые чувствительные; s08–s10 по плану — рубрика «для тех, кто постарше» |

Факты всех 10 — по памяти из 10-idey.md; перед сценарием проверить по списку «Проверить перед сценарием» там же.
